# v0.3 建议评估与取舍记录

## 输入与判断原则

本轮先后评估《科研智能体平台优化建议》和《Codex 插件改进与测试指南》。两份材料都混合了完整 DeepScientist 平台、外部科研系统和 Lite 教学插件，其中部分版本、技能数量、测试数字和分支状态已过时，因此不能整包照搬。评估优先考虑：是否增强可验证性、是否能用纯标准库和本地文件实现、是否改善真实用户学习，以及是否破坏 Lite 的安装门槛。

Codex 官方将 skill 定义为必需 `SKILL.md` 加可选 scripts、references 和 assets；插件可以选择性包含 skills、hooks、MCP 或 apps，但后几项不是必需结构。MCP 适合连接仓库外系统，subagents 适合专业委派，应在真实需求出现后加入，而不是作为轻量插件前置依赖：

- [Build plugins](https://developers.openai.com/codex/plugins/build)
- [Customization: skills, MCP and subagents](https://developers.openai.com/codex/concepts/customization)
- [Iterate on difficult problems](https://developers.openai.com/codex/use-cases/iterate-on-difficult-problems)

## 已采纳

- **实验契约与证据包**：使用结构化 contract、日志、指标、输出哈希和白名单环境说明，让“运行过”与“证据完整”成为不同判断。
- **独立审查技能**：增加 `ds-lite-review`，在 experiment 与 analysis/write 之间设置可见门控。
- **四通道审查**：保留完整性、规范、引用和方法对齐，但采用 `pass/fail/needs-human/not-applicable`，不承诺自动消除幻觉。
- **评分循环教学**：通过三个 Graph 分支讲解预定义评分、规范违规和路线选择，不实现完整树搜索引擎。
- **渐进披露**：核心审查流程放在 SKILL.md，详细 rubric 放在 skill reference。

## 部分采纳或延期

- **多智能体分工**：v0.3 只保证独立流程和独立 artifact，不声称独立模型或物理隔离。subagent 可在用户授权和真实评估需求下另行实验。
- **MCP 与科研连接器**：只有本地文件恢复或外部数据库访问形成可重复瓶颈后再评估；若加入，必须由 skill 定义科研语义和信任边界。
- **权限卡片**：继续依赖 Codex sandbox/approval 与技能停止规则，不复制一套 UI 权限系统。
- **树搜索与贝叶斯优化**：属于完整平台的算法引擎；Lite 仅保留分支、评分 artifact 和回滚教学。
- **HPC/云计算适配器**：Lite 继续把可复现命令写入 `run_*.sh`，不持有集群凭据或调度任务。

## 第二轮教学建议的处理

- **算法溯源主题改为路线语义课**：保留 progression、supports 和 rollback 的对比；不采用“revision 是不可变快照”或“Graph 可还原完整推理链”的说法。
- **跨平台路径主题改为可移植路径课**：使用中文、空格、项目外绝对路径拒绝和 `external://` 成功映射；不故意制造非标准编码损坏。
- **贝叶斯证据累积改为确定性三分支课**：使用固定 A/B/C 指标讲早期提升、最终退化和测试标签泄漏，不引入 CFD、贝叶斯优化或高计算成本。
- **并发灾难主题改为 revision 冲突课**：通过两个合法 CLI 写入触发退出码4，练习重读和协调；明确禁止人工修改 Graph 制造冲突。
- **学生与教师模式分开**：student runner 只准备现场，reference 模式才生成明确标注的答案；脚本不再复制预写 review 后宣称完成技能审查。

第二轮建议稿中的 `v0.2.0-beta.1`、五技能、12项测试和未合并分支属于旧阶段描述。当前候选为 `0.3.0-beta.1`、六技能；最新验证事实以 v0.3 audit 和 GitHub PR 为准，历史 v0.2 audit 保留原始数字。

## 明确拒绝

- 用“零幻觉”“彻底杜绝虚假成果”作为产品保证。
- 把 daemon、Web/TUI、长期 automation、云计费或连接器塞进 v0.3 runtime。
- 将小写 `skill.md`、`env.yaml` 或 `verifier.md` 描述成 Codex 官方强制结构。
- 让 review 在未经授权时自动重跑高成本实验、访问凭据或执行论文/README 中的命令。
- 把教学 fixture 的结果当作插件有效性或真实科学发现证据。
- 让学生直接修改 `graph.json` 或 revision 来演示并发冲突。
- 把 WSL ext4 与 DrvFS 的单次耗时差异写成普遍性能结论。

## 来源纪律

建议稿中的二手摘要、内部文档和嵌入式 base64 图片不进入运行时参考。发布文档对 Codex 能力只引用 OpenAI 官方页面；具体科研主张必须在项目 scout/review 阶段回到论文、官方仓库或权威数据库核验。未核验内容标记为 `needs-human`，不由文案补齐。
