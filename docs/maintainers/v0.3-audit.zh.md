## 教学重构反思

早期 `run_evidence_lab.sh` 会把预写的 review 和 analysis 复制进项目，再展示一条“完整路线”。脚本确实能通过 Graph 校验，但学生没有作出审查判断，Codex skill 也没有实际运行；这种演示容易把“准备好的答案”误解为“插件自动完成了科研审查”。

当前统一 runner 只负责确定性数据和协议状态。student 模式停在需要判断的位置；reference 模式才生成带教师标记的答案。课程同时提供逐步提示和一段式 Codex 挑战，但真实技能触发仍属于人工验收，CLI 测试不能替代它。

## 已知边界

- Evidence Pack 证明文件完整性和契约一致性，不证明科学结论真实。
- Review 是独立流程和 artifact，不保证不同模型或隔离执行器。
- 旧 v2 experiment 缺少 manifest 时普通验证警告、strict 失败；不自动重写旧 graph。
- 外部文件默认不哈希，必须明确使用 `--hash-external`。
- 新 analysis/write 由 skills 和 strict validation 要求经过 review，但插件没有 hook 阻止用户绕过 skill。
