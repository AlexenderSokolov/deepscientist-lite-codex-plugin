## 已知边界

- Evidence Pack 证明文件完整性和契约一致性，不证明科学结论真实。
- Review 是独立流程和 artifact，不保证不同模型或隔离执行器。
- 旧 v2 experiment 缺少 manifest 时普通验证警告、strict 失败；不自动重写旧 graph。
- 外部文件默认不哈希，必须明确使用 `--hash-external`。
- 新 analysis/write 由 skills 和 strict validation 要求经过 review，但插件没有 hook 阻止用户绕过 skill。
