# Project Communication Style

This optional contract controls conversational and narrative Markdown wording.
It does not control research decisions, evidence strength, execution permission,
or protected structured content.

```yaml
language: auto
detail: adaptive
academic: auto
profile: research-peer
extends: ""
```

## Defaults

- `language`: `auto`, `zh`, or `en`.
- `detail`: `adaptive`, `concise`, or `deep`.
- `academic`: `auto`, `on`, or `off`.
- `profile`: `research-peer`, `teaching-explainer`, `compact-operator`,
  `reflective-researcher`, or `custom`.
- `extends`: one built-in profile when `profile: custom` is used.

Add project-specific preferences under this line. Prefer positive, observable
requests such as sentence rhythm, terminology, audience, and examples. Do not
request author imitation, invented evidence, altered numbers, or hidden process.
