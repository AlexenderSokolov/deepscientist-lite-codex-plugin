# Math Exploration Template

Use this template when DS Lite needs a lightweight mathematical note rather than a full proof.

## Objects

Define the search space, objective, observations, budget, and algorithm family.

## Assumptions

Separate confirmed experiment facts from modeling assumptions such as smoothness, locality, hierarchy, noise, or kernel validity.

## Decomposition

Write the main quantity, then decompose it into interpretable terms. For search experiments this is often regret, error, cost, or risk.

## Algorithm Mapping

Map each compared method to one term in the decomposition. Explain what assumption each method exploits.

## Evidence Link

Point to experiment artifacts or result files that support or contradict the model.

## Next Mathematical Question

End with the smallest useful lemma, bound, counterexample, or diagnostic experiment to try next.
