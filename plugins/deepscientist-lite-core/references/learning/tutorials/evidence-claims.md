# 证据与主张

把主张拆成可核查的 claim，并为每条 claim 指向 Evidence Pack、日志、指标或来源。普通 Markdown、Factor Card、idea 标签和“看起来完成”的文件不能提升 evidence strength。review 的 verdict 与 claim assessment 分开记录；失败、负面和 inconclusive 都是有效结果。写作先建立 claim-evidence map，再决定语气；证据不足时写 placeholder 或 `needs-evidence`，不要用润色掩盖缺口。引用必须核对身份、内容和支持范围，来源不可用时记录 pending。
