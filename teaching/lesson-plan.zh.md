# 教学讲解流程

## 1. 为什么需要 Lite 插件

完整平台适合长期运行和系统展示，但教学时门槛高。Lite 插件把核心协议压缩成 Codex skills、模板文件和一个邻接表状态内核。

## 2. 核心概念

- `PROJECT.md`：项目级记忆。
- `STATUS.md`：当前节点和下一步。
- `research/state/graph.json`：机器可读研究图。
- `RESEARCH_MAP.md`：人类可读研究图投影。
- `research/artifacts/*.md`：每一步的证据记录。

## 3. 演示路线

1. 用一句研究问题启动 intake。
2. 生成项目记忆和状态图。
3. 增加一个 scout 或 idea 节点。
4. 记录一次实验或负结果。
5. 用 trace 回溯当前路线。

## 4. 讲给师兄的重点

Lite 不是另一个完整平台，而是 DeepScientist 方法论的教学内核。它先教会学生什么是可回溯科研工作流，再决定是否进入完整平台。
