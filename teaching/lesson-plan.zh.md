# 教学讲解流程

## 1. 开场：为什么需要 Lite 插件

完整 DeepScientist 平台适合长期运行和系统展示，但教学时门槛较高。DeepScientist Lite 把核心研究协议压缩成 Codex skills、模板文件和一个邻接表状态内核，让学生先理解“自动化科研为什么需要状态”。

## 2. 核心概念

- `PROJECT.md`：项目级记忆，记录背景、目标、验收标准和长期决策。
- `STATUS.md`：当前节点、阻塞和下一步，方便新线程快速接手。
- `research/state/graph.json`：机器可读研究图，是状态来源。
- `RESEARCH_MAP.md`：人类可读研究图，方便讲解和复盘。
- `research/artifacts/*.md`：每一步的证据记录，包括想法、实验、分析和失败。

## 3. 推荐讲解顺序

1. 从一句研究问题启动 intake。
2. 展示生成的项目记忆和状态图。
3. 增加一个 scout 或 idea 节点。
4. 记录一次小实验或负结果。
5. 用 trace 回溯当前路线。
6. 解释为什么这比聊天记录更适合长期科研。

## 4. 讲给师兄或学生的重点

DeepScientist Lite 不是另一个完整平台，而是 DeepScientist 方法论的教学内核。它先教会学生什么是可回溯科研工作流，再决定是否进入完整平台或更复杂的自动化系统。
