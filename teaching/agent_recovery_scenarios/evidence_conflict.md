# 证据冲突恢复

> 场景：两个会话产生了相互矛盾的证据，或同一数据的 artifact 给出不同结论。

## 症状

- `research/artifacts/` 中存在两个 artifact，对同一实验给出不同结果
- Graph 中某个节点有多个 `supports` 或 `contradicts` 边
- `STATUS.md` 中记录的结论与最新 artifact 不一致

## 恢复步骤

1. **识别冲突**：列出所有涉及冲突的 artifact 和 Graph 节点
2. **检查时间戳**：确认哪个 artifact 更新（但不自动认为新的就是对的）
3. **检查完整性**：确认每个 artifact 是否完整（hash 是否匹配、字段是否齐全）
4. **检查独立性**：确认两个 artifact 是否来自独立的数据源/代码/作者
5. **标记冲突**：在 Graph 中将该节点标记为 `ambiguous`
6. **记录冲突**：在 `STATUS.md` 中记录冲突的双方、证据强度和不确定范围
7. **寻求裁决**：如果冲突无法通过文件解决，标记为 `blocked` 并请求人类裁决

## 注意事项

- 不要静默选择一方而忽略另一方
- 不要把"不确定"写成"确定"
- 冲突保留是 DS Lite 的核心设计——负结果和矛盾都是科学证据
